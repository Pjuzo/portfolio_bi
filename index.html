Основные моменты

    Реализовала переход на новую систему отчетов BI и новую систему хранения данных - СУБД MS SQL.

    Прежняя система отчетов:

  • 1. источники в отчете - excel, csv, json и т.д.;
  • 2. длительное время загрузки, вызывающее раздражение пользователей;
  • 3. любое изменение, в том числе загрузка данных зачастую требовали ручных изменений.

    • Новая система отчетов:

  • 1. автоматизированная система отчетов, налаженные ETL процессы по получению и очистке данных (Python: Pandas, NumPy, SQLAlchemy, Plotly, fuzzywuzzy) из различных источников: StroyBot, Primavera, 1C, БД управленческого учета, данных электронных торговых площадок и файлов Excel, CSV и пр.
  • 2. минимизация времени загрузки, оптимизация SQL запросов (анализ плана запроса, индексов, использование оконных функций и пр.).
  • 3. прозрачные метрики отчетов, отвечающие заданной задаче.
  • 2. минимизация времени загрузки, оптимизация SQL запросов (анализ плана запроса, индексов, использование оконных функций и пр.).
