Основные моменты

    Осуществила переход на новую систему отчетов и новую систему хранения данных - в базе данных SQL.

    Прежняя система отчетов:

  • 1. источники в отчете - excel, csv, json и т.д.;
  • 2. длительное время загрузки, вызывающее раздражение пользователей;
  • 3. любое изменение, в том числе загрузка данных зачастую требовали ручных изменений.

    • Новая система отчетов:

  • 1. полностью автоматизированная система отчетов, налаженные ETL процессы по получению и очистке данных из специализированных программ: StroyBot, Primavera, 1C, баз управленческого учета, данных с электронных торговых площадок и множества источников в Excel.
  • 2. минимальное время загрузки из хранилища данных SQL с помощью оптимизированных запросов.
  • 3. прозрачные метрики отчетов, отвечающие заданной задаче.
  • 4. индивидуальный подход к требованиям бизнес-заказчиков, в том числе через реализацию требуемого визуала с помощью SVG, CSS и HTML.
