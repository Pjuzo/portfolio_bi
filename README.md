# EDA продаж - Jupyter Notebook

1. Сценарий.
   Предварительный анализ данных о продажах. Цель: понять основные драйверы выручки, влияет ли удовлетворенность покупателей, соблюдение сроков доставки и пр. Определение зон, где можно было бы повысить коммерческую эффективность.
   

2. Инструменты
- Python
	- pandas
	- numpy
	- Matplotlib / Seaborn
	- Jupyter Notebook

3. Основные выводы
- Скидки более 25% составляют 25% выручки и 29% от общего количества товаров. Тем не менее они не оправданы по всем категориям товаров.
- На рейтинги покупателей не влияют ни высокие скидки, ни увеличение срока доставки. 
- С помощью RFM анализа покупатели были условно разделены на 8 групп. 78% выручки приносят 4 категории:
	"чемпионы" - частые недавние покупки с высоким чеком. Стратегия удержания - предложить персональное обслуживание.
	"лояльные / высокая стоимость" - выше среднего по всем показателям. Цель увеличение количества покупок и стоимости - рассылки с выгодными акциями и предложениями, подборки рекомендаций.
	"риск — высокая стоимость" - те, кто раньше совершали частые и дорогие покупки, но сейчас, вероятно, ушли к конкурентам. Цель - возвращение. Проанализировать отзывы этой группы покупателей, возможно это позволит выяснить причину их ухода. Направить краткую анкету обратной связи, отправить скидку, новость о распродаже или персональную подборку товаров, на основе прежних вкусов этих покупателей.
	"недавние частые с низким чеком" - цель увеличение количества покупок и стоимости - рассылки с выгодными акциями и предложениями, подборки рекомендаций, предложение сопутствующих товаров.
